# Casos de revisión del radar

Los casos de `tests/fixtures/review_cases.json` son ejemplos históricos sintéticos y revisados para evitar regresiones de contrato. No son noticias actuales ni afirman demanda o viralidad real.

- Una calculadora de tarifa separa una regla pendiente de su resultado.
- Un simulador deportivo separa reglas contrastadas de escenarios hipotéticos.
- Un juego educativo se sostiene en una mecánica reproducible, no en un dataset forzado.
- Una guía con fuente bloqueada conserva incertidumbre: el bloqueo no prueba falsedad.
- Una utilidad de archivos puede partir del mismo evento que otra propuesta si resuelve una necesidad distinta.

Las pruebas verifican estados de evidencia, formatos, compatibilidad y deduplicación determinista. La calidad editorial de una idea se revisa por una persona: el modelo no se califica a sí mismo.
